# Website

The official website for the Google Developer Group in NYP.

## Installation

### Prerequisites

- Node.js
- pnpm

### Setup

1. Clone repository: `git clone https://github.com/nyp-gdg/website`
2. Install dependencies: `pnpm install`
3. Start server: `pnpm dev`
